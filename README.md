# LINFISH

會員制水族電商專案。

目前已完成 Angular 前端畫面原型，後續預計加入 ASP.NET Core API、Supabase PostgreSQL／Auth／Storage，並分別部署到 Cloudflare Pages 與 Render。

## Workspace

```text
LINFISH/
├─ frontend/       Angular 商城與管理後台
├─ backend/        ASP.NET Core API（後續建立）
├─ database/       Supabase migration／seed（後續建立）
└─ docs/           架構與串接說明
```

詳細前端說明請見 [frontend/README.md](frontend/README.md)。
